BusCatcher 3000

HCDE 439 Final Project

What is it?

I made this project to help me get to the bus on time. Instead of having to frequently get my phone out and check Apple Maps I can instead glance at this display which shows me the next scheduled bus as well as the current time. When the bus is 5 minutes away, 4 red LEDs blink to alert me to get ready. This project was created for HCDE 439 Physical Computing at the University of Washington.

  char time[6];  // to store in hh:mm format
  Arrivals nearest = {0,0}; // initalize to store next arrival time
  if (rtc.dayOfWeek() == 1) { // if Sunday
    nearest = findNextSun(hour, minute);
  } else if (rtc.dayOfWeek() == 7) { // if Saturday
    nearest = findNextSat(hour, minute);
  } else { // weekdays
    nearest = findNextMF(hour, minute);
  }
  sprintf(time, "%02d:%02d", nearest.hour, nearest.minute);
  lcd.print(time); // print arrival time to LCD
  
  Serial.print("Next bus at: "); // print next arrival to serial monitor
  Serial.println(time);


  lcd.setCursor(0, 1); // move cursor to bottom left
  lcd.print("Time: ");

  
  char currentTime[6];  // to store in hh:mm format
  sprintf(currentTime, "%02d:%02d", rtc.hour(), rtc.minute());

  Serial.print("Current Time: "); // current time to serial monitor
  Serial.println(currentTime);

  lcd.setCursor(6,1); // set cursor middle bottom
  lcd.print(currentTime); // print current time to LCD


  // Blink 4 red LEDs on/off (1s intervals) for 1 minute starting 5 minutes before the next bus arrival.
  // Will not trigger if the turnover between two arrivals is less than 5 minutes. E.g 7:40 -> 7:43, will not trigger
  // a 7:38 alert.
  if ((nearest.hour * 60 + nearest.minute) - (rtc.hour() * 60 + rtc.minute()) == 5) { 
    if ((millis() / 1000) % 2 == 0) {
      digitalWrite(L1, HIGH);
      digitalWrite(L2, HIGH);
      digitalWrite(L3, HIGH);
      digitalWrite(L4, HIGH);
    } else {
      digitalWrite(L1, LOW);
      digitalWrite(L2, LOW);
      digitalWrite(L3, LOW);
      digitalWrite(L4, LOW);
    }
  }

  delay(1000); // wait 1 second
  
}

// determine next arrival based on weekday arrival times. 
Arrivals findNextMF(int hour, int minute) {
  Arrivals nearest = {0,0}; // initalize to store return value
  for (int i = 0; i < sizeof(mfSB) / sizeof(mfSB[0]); i++) { // for length of arrivals
    // Serial.println(mfSB[i].hour);
    if (mfSB[i].hour < hour) { // skip past arrivals
      continue;
    } else if (mfSB[i].hour == hour){
      if (mfSB[i].minute < minute) { // skip past arrivals within the hour
        continue;
      } else {
        nearest.hour = mfSB[i].hour;  // arrival hour
        nearest.minute = mfSB[i].minute; // arrival minute
        return nearest; // arrival time
      }
    } else { // check the next item in arrivals in case the next arrival is in the 
        next standard hour (E.g. checking 0700 but next is arrival is 0805)
      if (i < sizeof(mfSB) / sizeof(mfSB[0])) { // check not at end of arrivals
        nearest.hour = mfSB[i].hour;
        nearest.minute = mfSB[i].minute;
        return nearest; // arrival time
      } else {
        Serial.println("No more arrivals for the day");
        break;
      }
    }
  }
}

// Same as the weekday function but uses the Saturday arrivals data.

      }
    }
  }   
}

Technical Implementation

Hardware Components

  • Arduino Uno R3
  • Breadboard
  • DS1307 RTC Module
  • LCD1602 Display Module
  • 4 Red LEDs
  • Resistors ( 4-220Ω, 1-10kΩ)
  • 23 Jumper Wires, 19 Prototyping Wires
  • 10k Potentiometer
  • Cardboard, 18x9x9in box

Circuit Description

The circuit consists of an Arduino Uno connected to a DS1307 RTC module and an LCD1602 display module. The RTC needs to be programmed with the current time when the code is uploaded. Time can be edited in the code. Four red LEDs are connected to digital pins 7-10 through 220Ω resistors, which serves as the blinking 5 minute alert. A 10k potentiometer is used to adjust the contrast of the LCD display. The entire setup can be powered by connecting the Arduino board to power. I used a 9V outlet adapter.

Code Explanation

The code is written in C++ using the Arduino IDE. Install the "LiquidCrystal.h" and "uRTCLib.h" libraries.

To have access to estimated arrival times for my bus stop, I hard coded the arrival times for the southbound bus. I also included northbound but did not create functions for that direction. In the loop function, the code alternates between printing to the LCD and determing time using the RTC. First the real time is printed and then the next arrival is determined using the findNext functions, which return the next arrival times from the Arrivals object. See inline comments for more details.

Further Development

  • Simplify my code by creating one function that determines what day it is and then determines what the nearest arrival is rather than have separate functions for weekday, saturday, and sunday. I also would probably store time in minutes and then convert to hh:mm to print. It is much harder to work with hours and minutes separately.
  • Use a 3.3V to 5V level shifter to connect an ESP32 microcontroller to the Arduino. This could replace the RTC and provide updated time without having to manually reset the RTC when power is disconnected.
  • Obtain OneBusAway API key and implement live bus arrival times using ESP32 with a Python script.
  • Upgrade LCD to a large LED matrix (~64x32) to display on larger screen, allowing for more information such as weather and additional later arrivals.
